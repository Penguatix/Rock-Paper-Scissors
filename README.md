# ✂️ Rock Paper Scissors

A standalone, interactive browser game of Rock Paper Scissors where you face off against an RNG-based computer opponent. 

**🌟 Play it live here:** [Click to view the Live Demo](https://penguatix.github.io/Rock-Paper-Scissors/)

## 🚀 About This Project
This project brings the classic hand game to the web. It features a fully functional game loop with dynamic DOM updates, real-time score tracking, and conditional color-coded feedback based on match results.

### Features
* **Live Deployment:** Fully hosted and playable directly in your browser via GitHub Pages.
* **RNG Opponent:** Uses JavaScript `Math.random()` to ensure fair, unpredictable computer choices.
* **Live Scoreboard:** Tracks Player wins versus Computer wins across multiple rounds without needing to refresh the page.
* **Dynamic Visual Feedback:** Text display updates instantly with choices and dynamically changes color based on the match result (Neon teal for a win, red for a loss).

## 🛠️ Technologies Used
* **HTML5:** Semantic layout and emoji-based interactive buttons.
* **CSS3:** Flexbox for layout alignment, custom dark-theme styling, and hover animations.
* **Vanilla JavaScript:** DOM manipulation, conditional statements (Switch/If-Else), and Random Number Generation.
